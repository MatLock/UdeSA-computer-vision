# Synthetic Google Ads Feed Data

This folder contains **synthetic product data** generated from the first 500 rows
of each product-type CSV (`pants_tags.csv`, `shoes_tags.csv`, `tops_tags.csv`).

## Files

| File | Product Type | Rows | Purpose |
|---|---|---|---|
| `pants_google_500.csv` | Pants | 500 | Enrich + test the Merchant feed for pants |
| `shoes_google_500.csv` | Shoes | 500 | Enrich + test the Merchant feed for shoes |
| `tops_google_500.csv` | Tops | 500 | Enrich + test the Merchant feed for tops |

## Data Model

Each row contains:

### Original fields (from the source CSV)
- `id` — product ID
- `image_url` — URL to product image
- `relative_path` — local image path (after download)
- Product-type-specific tags (e.g., `pocket_details`, `fit_silhouette`, `season` for pants)

### Business fields (synthetic, user-supplied in production)
- `brand` — randomly chosen from a pool (StyleCo, FashionHub, TrendWear, etc.)
- `price` — random realistic price (19.99–149.99 USD)
- `gtin` — generated fake but valid GTIN-13
- `availability` — always `in_stock` for this synthetic dataset
- `link` — fake product URL (e.g., `https://store.example.com/pants/11876597`)
- `condition` — always `new`

### Inferable fields (generated by the enrichment pipeline)
- `title` — structured format (Brand + Gender + Color + Material + Fit + Type)
- `description` — short 2-3 sentence description derived from tags
- `gender` — one of `female`, `male`, `unisex`
- `material` — Cotton, Polyester, Denim, Linen, Wool, Silk, Cotton Blend
- `pattern` — Solid, Striped, Checkered, Floral, Abstract, Geometric
- `color` — one of 9 common colors
- `size` — XS, S, M, L, XL, XXL
- `age_group` — always `adult`
- `google_product_category` — Google Shopping taxonomy path (e.g. "Apparel & Accessories > Clothing > Pants")

## Usage

### Testing the enrichment pipeline (Milestone 1)
Use these CSVs to validate that the enrichment logic (gender, material, pattern, category, title)
correctly processes products.

### Testing the Merchant feed validator (Milestone 2)
Feed these CSVs through the validator to ensure all required fields are present and in the
correct format (GTIN checksum, price format, etc.).

### Testing the publishing pipeline (Milestone 3)
Upload these CSVs to a **test/sandbox** Merchant Center account (free; see `upgrade/requirements.md`)
to validate that the Merchant API integration works end-to-end.

### Testing the optimization loop (Milestone 4)
Create a test campaign from these CSVs and simulate metric retrieval + optimization rules.

## Important notes

- **Data is synthetic/fictitious.** GTINs, prices, links, and brands are not real.
- **Safe for testing.** These are designed to be fed to test/sandbox Google accounts
  (which don't serve real ads or charge).
- **Do NOT use in production.** Real GTINs must be valid, prices must be real, and links
  must be active for the feed to be approved.
- **Regenerate anytime.** Run `python3 upgrade/generate_synthetic_data.py` from the project root
  to regenerate these files.
